How it works

Step 1: Select a creation or search for it. Step 2: Inspect recorded source changes and open the attached coding lesson. Step 3: Add personal plans, checklists, and learning notes. Step 4: export your notes as a backup. Source history is periodically rebuilt from accessible GitHub repositories; it never claims an unverified deployment.

Important: Your notes save in this browser unless you export them. Automatically generated lessons explain the changed code, but still require human review for completeness. Source changes in private repositories are not published by this dashboard.
