TEMPLAR’S WONDERWORLD — HISTORY EXPANSION

Open index.html in a modern desktop or mobile browser. Keep the whole folder together. It runs offline; museum links require internet.

History House: 10 wings x 10 chapters; 10 x 20-question timed quiz rounds per wing (100 quiz attempts total), using each wing’s 20-question bank reshuffled across rounds; 20 additional self-reviewed projects per wing (200). Total 300 assignments and activities, but NOT 2,000 unique questions. 200 authored question variations based on 100 factual lesson topics. Quiz scores and activity drafts save in this browser via localStorage; export is not available.

Game Night: four new history-themed games — Family Challenge (not actual survey data), Scholar Showdown, Spin the Phrase, Rapid-Fire. Family_Game_Night original is retained with a link to History Game Night.

The package is a standalone add-on, not a direct modification of the pre-existing Wonderworld website or any deployed GitHub repo. To link from existing site add relative link to this folder/index.html after uploading whole folder.

Historical learning note: This is an introductory self-study resource. Follow linked museum and reference websites for fuller primary evidence. Historical depictions avoid gamifying suffering.
