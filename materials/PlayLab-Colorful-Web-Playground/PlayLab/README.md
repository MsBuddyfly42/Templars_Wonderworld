# PlayLab
A colorful, fully interactive practice website.

Open `index.html` in your browser.

Practice ideas:
- Edit text in index.html
- Change colors in styles.css
- Add ideas, themes, emoji pairs, or phrases in app.js
- Break something on purpose, then fix it
- Add your own section or mini-game

Nothing in this folder is connected to your real S3LFM@DE Solutions website.
