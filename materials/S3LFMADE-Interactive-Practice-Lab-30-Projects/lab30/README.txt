S3LFM@DE SOLUTIONS — INTERACTIVE PRACTICE LAB
==============================================

PURPOSE
This folder is a safe practice area. It does NOT connect to your live business website, Stripe, email, database, or customer portal.

HOW TO OPEN IT
1. Keep all files together in the same folder:
   - index.html
   - styles.css
   - app.js
2. Double-click index.html.
3. It should open in Chrome, Edge, Firefox, or another browser.

HOW TO PRACTICE
- Choose a project from the left side.
- Fill in the fields manually.
- Press CHECK MY WORK to see what is correct or missing.
- Press PREVIEW to see your information in a formatted card.
- Press LOAD SAMPLE if you want an example to study.
- Press SAVE DRAFT to save your practice data in that browser on that device.
- Press RESET to clear the current form.

WHAT TO EDIT WHILE LEARNING
- index.html = page structure
- styles.css = colors, spacing, fonts, layout
- app.js = buttons, fields, validation rules, sample data, calculations

SAFE EXPERIMENTS
- Change a label.
- Add a field.
- Make a required field optional.
- Change the minimum character count.
- Add another dropdown choice.
- Change the colors in :root inside styles.css.
- Add a new practice project by copying one project object in app.js.

TESTING CHALLENGE
For each project:
1. Submit it with everything blank.
2. Enter one wrong field on purpose.
3. Fix it and test again.
4. Load the sample and compare it to yours.
5. Preview your completed work.
6. Save the draft, refresh the browser, and make sure it returns.

PORTFOLIO TIP
Before posting practice work publicly, replace sample names/contact details with your own fictional demo data and label it as a concept or practice sample when it is not real client work.
