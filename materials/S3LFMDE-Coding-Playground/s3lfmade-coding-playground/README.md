# S3LFM@DE Coding Playground

This is a **practice-only** website. It is completely separate from the live S3LFM@DE Solutions site.

## Files
- `index.html` — page structure and content
- `styles.css` — colors, spacing, layout, responsive design
- `script.js` — buttons, calculator, form validation, localStorage

## How to run it
1. Unzip the folder.
2. Double-click `index.html` to open it in your browser.
3. Open the folder in VS Code, Notepad++, or another code editor.
4. Edit one file.
5. Save.
6. Refresh the browser.

For the best experience, use VS Code with the **Live Server** extension, but it is not required.

## Beginner challenges
1. Change the main heading.
2. Change the gold accent color in `:root` inside `styles.css`.
3. Add a fourth service card in `index.html`.
4. Change the rush fee in `script.js` from `1.25` to `1.40`.
5. Add a phone field to the contact form.
6. Change the dark-mode background.
7. Add another random prompt to the `prompts` array.
8. Add a new section called “Portfolio”.

## Intermediate challenges
1. Add a filter button that hides/shows service cards.
2. Add a second quote option such as “Same-day service”.
3. Save the quote estimator values in localStorage.
4. Build a modal popup without a library.
5. Add a mobile hamburger menu.
6. Add a fake customer order tracker using JavaScript objects.

## Important
Nothing in this playground sends email, takes money, changes your live website, or connects to customer data.
