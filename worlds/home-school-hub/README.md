# Home School Hub

A browser-based “school away from school” starter application with separate Student and Parent portals.

## Included
- Daily bell schedule and school-day progression
- Locker, classrooms, cafeteria, recess, gym, principal’s office, and achievement hall
- Student tasks stored locally in the browser
- Parent dashboard for progress review

## Run locally
Open `index.html` in a modern browser. No installation is required.

## Demo credentials
- Student: select a sample student profile
- Parent passcode: `PARENT-DEMO`

## Privacy and security
This is a front-end prototype. It uses local browser storage and does not have real authentication, secure cloud storage, or a database. Do not use it to store sensitive student information until secure accounts and a protected backend are added.
